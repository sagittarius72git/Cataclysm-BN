# 足りない部品を作る (Craft Missing Parts)

作りたい品や建設したいものを選ぶと、足りない部品を自動で作ってそろえるMODです。
部品の部品が足りないときも、作れるところまでさかのぼって作ります。

**本体の新しいLua機能（PR #10477）が必要です。** このフォークの dev ブランチには入っています。入っていない本体では、メニューを開くとお知らせが出るだけで、何もしません。

## 使い方

1. アクションメニュー →「足りない部品を作る」を開く
2. 「作りたい品を選ぶ」か「建設したいものを選ぶ」で、名前の一部を入れて目標を選ぶ
3. 足りないものと、それぞれ作れるかが表示されるので、「はい」で開始

- **製作**：部品がそろうと、目標の品も作ります。
- **建設**：材料がそろったら知らせます。建てるのは建設メニューからです。
- 実行中にもう一度メニューを開くと「やめる」を選べます。

## しくみ

- 部品を1つ作るたびに、**手持ちと周り6マス以内**を見直して、次に作るものを決めます（本体の製作と同じ範囲）。
- 製作は本体の製作メニューと同じです。技能・失敗・かかる時間も同じで、材料の選び方などを聞かれたら答えてください。
- 作り方が複数あるときは、今すぐ作れるものを優先します。
- 対象は**あなたが知っているレシピ**だけです。

## 注意

- 道具の「品質」（切断・打撃など）が足りないときは、自動では作りません。確認画面と止まったときのお知らせに、必要な品質が出ます。
- 製作が中断・失敗すると止まります。作りかけの品があれば仕上げてから、メニューの「続きから」で再開してください。
- 予想外のくり返しを防ぐため、部品を50回作るか、同じ部品を20回作ると止まります。

## 設定

`main.lua` 冒頭の `CFG` で変えられます。

- `max_depth`：部品の部品…とさかのぼる最大の段数
- `max_crafts`：1回の実行で部品を作る最大の回数
- `max_same`：同じ部品を作る最大の回数
